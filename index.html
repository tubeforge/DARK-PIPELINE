About

The Dark Pipeline is a YouTube content automation tool. Generate complete production packages — scripts, image prompts, and metadata — powered by Claude AI.

Your API key is stored locally on your device and never shared.

Workflow Guide

1️⃣ Generate Pipeline → get script + image prompts + metadata
2️⃣ Copy script → paste to ElevenLabs → download MP3
3️⃣ Copy image prompts → generate in Midjourney / Leonardo
4️⃣ Import voice + visuals into CapCut
5️⃣ Copy metadata → paste when uploading to YouTube
